## 完成约束

- 依 C1–C7 顺序推进；紧密相关内容可在同一批处理，但不得因一处修订推断整批完成。
- 注释必须准确描述实际代码契约。独立摘要为三行；构造函数使用“初始化一个 `<see cref="当前类型"/>` 类型的实例。”，属性按访问器写“获取……”“设置……”“获取或设置……”或“获取或初始化……”。公共契约核对单位、默认值、空值、所有权和错误；重写成员仅在上游文档有效时继承；参数、泛型参数和返回说明必须与签名及行为一致。
- 只有当前入选范围内的全部声明审计通过、严格 XML 诊断构建通过、重载与继承关系复核通过，才能标记当前批次验收完成。
- C# 非注释 token 相等是验收要求。历史实施没有初始 token 快照，因此该历史变更无法追溯证明；未来每轮须在编辑前生成并保留可比较基线。
- 只改文档注释，不改变业务语句、签名、可见性、默认值、依赖、版本、JSON 格式或目标框架；不提交、不推送、不发布。
