## 变更与影响

- 模板文字和条码新增顺时针 `Rotation`，文字新增旋转前行宽 `Width`。布局轨迹返回角度及旋转后尺寸。
- 旋转后的占位用于单元格边界、结束坐标和分页。旋转文字块不可拆页，空行保留间隔且不输出空字形命令。
- TSPL Provider 将占位左上角换算为原生旋转锚点；ZPL 新增支持条码旋转的重载。旧 CPCL 和原始 TSPL 命令 API 保持原有角度/字节语义。
- 设计器支持选择角度、预览、尺寸反向回写和 JSON 往返；离线预览不再重复旋转结束坐标框。
- 涉及 Core、Templates、DesignerHost、Vue 设计器；公开模型、跨 Provider 坐标转换和模板文件契约有新增。风险：MEDIUM。目标框架、依赖、版本及打包配置没有改动；不涉及 Benchmark Harness。
